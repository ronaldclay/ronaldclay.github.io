# 🌻 Día de las Flores Amarillas

## Cómo verla

```bash
python3 -m http.server 8000
```

Luego abre **http://localhost:8000** en el navegador.

Alternativas: `npx serve .`

---

## ✏️ Cómo cambiar las frases

Todo lo que quieres personalizar está en **`config.js`**.

---

## Controles

- **Arrastrar** con el ratón o el dedo → girar la cámara alrededor de la escena.
- **Rueda del ratón** o **pellizcar** en móvil → acercar y alejar.
- Toca la pantalla de inicio para empezar (ahí arranca la música).
